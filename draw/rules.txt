作画守则（模板 · 可直接改成你自己的）
======================================

这份文件的作用只有一个：每次出图之前，逼自己把规矩读一遍。
读到底之后，用 draw/open_draw.py 取本文件 sha256 的前 8 位，把码输回去才算「开画」。
默认 2 小时有效；**本文件改一个字，码就变，旧的开画立刻作废**——这是设计，不是 bug。


一、开工顺序
------------
1. 先读完本文件，再取码开画。
2. 有参考图、或要在已有图上改 → 用图生图（img2img）保底图，不要重新从头生成。
3. 一次只改一个变量：衣服 / 光 / 姿势，三选一。同时改两个，出了问题分不清是谁的锅。


二、固定配方（写错就等于换画风）
--------------------------------
- 正向开头：masterpiece, best quality, very aesthetic, absurdres
- 尺寸 832x1216；34 步；cfg 8；采样器 euler / 调度器 normal
- 模型必须显式写：--ckpt=<你的底模文件名>
  （不写就会退回脚本默认模型，脸和笔触立刻飘）
- 角色特征每张写全：发色、瞳色、标志物。它不继承上一张的上下文。
- 质感词最多两三个；写到五个就开始变塑料。


三、改图幅度（denoise 的用法）
------------------------------
- 只换衣服：0.55 ~ 0.60，并把旧材质写进负向提示词。
- 只提清晰度：hires 放大 1.2 倍以内；源图长边 × 倍率不要超过 1500，超了会顶爆显存。
- 想换画风或重铺笔触：0.45 ~ 0.50，代价是构图会跟着走。


四、出图自检四项
----------------
脸 / 姿势 / 光 / 衣服。

有一项不对，就退回上一版重做；**不要在错的那一版上继续叠**。


五、每张必须留档
----------------
往笔记里追加一行：

    时间 / 源图 / 正向 / 负向 / denoise / steps / 种子 / 输出名

留档不是为了好看，是为了倒查：
同一串提示词换个种子，笔触会从软光厚涂跳到平涂硬线；
翻笔记能找回上次那个种子，比重新调半天词快。


六、不许做的事
--------------
- 不许靠贴图拼出成品。模型给不出来的东西，就承认这张做不出来。
- 不许删掉「自检」和「留档」这两条——那是这份守则里唯一能救命的。
- 涉及真人的图，先想清楚你能不能承担它的传播。
- 模型权重、私人提示词、私人照片，不进公开仓库。


七、这份文件可以自己改
----------------------
- 上面六节是骨架，不是法律。觉得哪条不合你的用法，就改掉；用的是你自己，不用讨好谁。
- 也可以加条：比如「不许画某类题材」「一次最多出几张」——写你真正会犯的那个错。
- 改完必须重新开画（因为码变了）：改一句 → 跑 open_draw.py → 输新码。
- 想换时长：open_draw.py --hours 8；看状态：--status；立刻关闸：--close。
- 只写它管的事。来历、起名理由、改版记录，别往这里塞——那是 README 的活。
