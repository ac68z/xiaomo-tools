# dsh-tool-surface

上下文里**只放工具目录**（名字＋一句话），参数细节留在 `docs/工具细则/*.txt`，按需读。
这个插件负责解决「想不起来还有这只手」：每轮拿刚进来的那句话去本地浮现服务问一句
「这像在找哪个工具」，命中的一两条作为 `<tool-surface>` 提醒折进本轮上下文，
提醒里带工具名、一句话和细则 TXT 的绝对路径。

- 服务：跟记忆浮现共用同一个进程 `star-map/memory_surface_daemon.py`（127.0.0.1:8799），
  端点 `POST /tools {q, n, min}`；工具索引在 `docs/工具细则/_索引.tsv`（工具名 / 一句话 / 触发词）。
- 只提醒、不执行；超时或服务不在就安静跳过。
- 同一句话 10 分钟内只提一次；每轮最多两条。
- 环境变量：`DSH_TOOL_SURFACE_PORT`（默认 8799）、`DSH_TOOL_SURFACE_MIN`（默认 0.47）。

## 与记忆浮现的分工

| 插件 | 管什么 | 配额 |
|---|---|---|
| dsh-memory-surface | 旧事：记忆 / 工程笔记 / 词典 | 3 / 2 / 1 |
| dsh-tool-surface | 手：81 个工具的目录 | 2 |

分开的理由：触发节奏不同。记忆是「聊到旧事就该浮」，工具是「这句像在要一个动作才该浮」；
混一起配额会互相扯，出问题也不好定位。
